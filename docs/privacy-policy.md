# Focus Reader — Privacy Policy (Draft)

**Last updated:** September 1, 2026  
**Status:** Draft — review before publishing at a public URL for Chrome Web Store submission

## Summary

Focus Reader processes text **locally in your browser**. We do not collect, store, or transmit your highlighted text to any servers in v1.

## Information We Process

When you highlight text on a webpage and choose **Read with Focus Reader**, the extension:

- Reads the text you selected
- Splits it into chunks for display in the reader UI
- Keeps that text in memory for the duration of your reading session

This processing happens **on your device**.

## Information We Do Not Collect (v1)

- We do not send selected text to external servers
- We do not use analytics or tracking in v1
- We do not create user accounts
- We do not sell personal data

## Permissions

Focus Reader requests Chrome permissions only to:

- Add a context menu item when you select text
- Display the reader in the Chrome Side Panel

Each permission is used solely to provide reading functionality. See the extension’s Chrome Web Store listing for the current permission list.

## Data Storage

v1 does not persist your reading text beyond the active session unless explicitly added in a future version. If session storage is used, data remains on your device and is cleared when the session ends.

## Future Features

If later versions add optional features (e.g. cloud-based simplification, accounts, or analytics), this policy will be updated **before** those features ship. Optional cloud features will require **explicit user consent**.
